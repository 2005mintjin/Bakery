# 작은 화덕 · 달빛마을
평화로운 마을에서 빵을 굽고 이웃의 이야기를 듣는 웹게임 프로토타입입니다. 기존 런앤건과 독립된 신규 프로젝트입니다.

## Windows에서 시작
1. 최초 한 번 [Node.js](https://nodejs.org/) LTS(20 이상)를 설치합니다.
2. `게임 실행.bat`을 더블클릭합니다. 로컬 서버 준비 후 브라우저가 열립니다.
3. 게임 종료 후 서버 창에서 Ctrl+C를 누릅니다.

패키지 설치는 필요 없습니다. `index.html` 직접 열기는 JSON 로딩 때문에 지원하지 않습니다. 포트 5173을 다른 프로그램이 사용하면 해당 프로그램을 종료하세요. 같은 주소/브라우저로 접속해야 기존 저장을 불러옵니다.

## 개발
`npm start` → 로컬 서버, `npm test` → 핵심 시스템 테스트. 파일 수정 후 브라우저 새로고침으로 반영됩니다. 인터넷 없이 실행 가능하며 화면은 비율을 유지합니다. 마우스로 캐릭터를 이동하지 않으므로 캔버스 좌표 변환 의존성이 없습니다.

## 조작과 첫 플레이
- WASD / 방향키: 이동, E: 대화·조사, I: 가방, J: 퀘스트, ESC: 메뉴/닫기.
- 대화 버튼 클릭 또는 Tab/Enter로 선택합니다. E/Space도 첫 선택지를 진행할 수 있습니다.
- 광장 왼쪽 위 **작은 화덕 문**으로 걸어 들어갑니다. 실내 아래쪽 문으로 나옵니다.
- 화덕, 진열대, 재료 상자의 **아래쪽**에 접근해 E를 누릅니다.
- 화덕에서 밀빵을 구워 미라에게 가져갑니다. 퀘스트 물품은 진열하지 않고 가방에 보관하세요.
- 오른쪽 베리 덤불에서 E로 베리 3개를 수확해 준에게 전합니다. 게임 시간 30분 후 재수확 가능합니다.
- 소라의 부탁을 수락한 다음 다시 대화해 격려하면 퀘스트가 완료됩니다.
- 밀빵/꿀빵/베리빵을 진열한 후 '손님맞이'로 판매합니다. 수익은 즉시 정산됩니다.
- 메뉴에서 직접 저장/불러오기. 자동 저장은 없습니다. 메뉴의 다음 날 아침은 시간을 넘기며 물품과 퀘스트를 유지합니다.
- 대화/메뉴 중 시간은 멈춥니다. 현실 1초는 게임 2분입니다. 밤의 강제 귀가/손해는 없습니다.

## 구조와 확장
- `src/main.js`: 부팅·입력·게임 루프, `player.js`: 이동·충돌
- `sceneManager.js`, `exploration.js`, `renderer.js`: 맵 전환·상호작용·픽셀 렌더링
- `dialogue.js`, `npc.js`, `quest.js`: 대화·주민·부탁
- `bakery.js`, `inventory.js`: 제작·진열·판매·재료
- `ui.js`, `saveSystem.js`: 패널·로컬 저장
- `data/*.json`: 대사/주민/퀘스트/레시피. NPC의 id와 quest 참조를 맞춰 추가합니다.
- `assets/characters`: 정면 픽셀 SVG. 맵과 걷기 캐릭터는 renderer의 픽셀 드로잉으로 생성합니다. 나머지 assets 폴더는 후속 이미지/음원용입니다.

표정은 NPC별 이미지 키를, 관계는 저장 상태 affinity를 확장할 수 있습니다. 현재 호감도는 퀘스트 완료 시 내부적으로만 증가합니다. 사운드는 아직 없습니다. 정면 대화 배경은 현재 장소에 따른 색상 기반 임시 배경입니다. 실제 손님 AI 대신 명시적인 판매 정산을 사용합니다.

Git 변경 확인: `git status`, `git diff`; 원하는 단위로 `git add` / `git commit` 후 연결된 GitHub 원격으로 푸시하세요. 첫 커밋과 원격 푸시는 자동 수행하지 않습니다.

## Windows 실행 오류 해결
`게임 실행.bat` 또는 영문 이름 `launch.bat`을 실행하세요. 배치 파일은 ASCII 내용과 Windows CRLF 줄바꿈을 사용합니다. ZIP 안에서 실행하지 말고 전체 파일을 먼저 압축 해제하세요. 기존 버전에서 `C:\Windows\System32\server.js` 오류가 났다면 최신 파일로 교체하세요. Node.js 재설치는 필요하지 않습니다.

수동 실행: 게임 폴더를 탐색기로 열고 주소창에 `cmd` 입력 → `node server.js` 실행 → 브라우저에서 `http://127.0.0.1:5173` 접속.
