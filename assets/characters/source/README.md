# 사용자 제공 캐릭터 원본

Downloads.zip의 원본 바이트를 그대로 보존합니다.

- sheet-1.png: 라쿤 꼬리 캐릭터 픽셀 스프라이트 시트.png (1983×793), 4방향 걷기.
- sheet-2.png: 라쿤 꼬마 캐릭터 픽셀 스프라이트 시트.png (1536×1024), 대기·걷기·점프·빵 포즈·표정.

이번 구현은 두 번째 원본의 첫 줄 대기 자세와 첫 번째 원본의 걷기를 사용합니다. 두 번째 원본의 넷째 줄(y=612..836)은 후속 빵 운반 기능용으로 유지합니다. 원본을 지우거나 점프 포즈로 덮어쓰지 않습니다.

실행용 프레임과 위치는 tools/build-player.py에서 추출하고 data/playerAnimations.json으로 관리합니다. 원본의 색상이나 디자인을 새로 생성하지 않습니다.
