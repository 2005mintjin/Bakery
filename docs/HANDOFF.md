# 개발 인계 · 마을회관과 조합 등급

## 작업 기준

현재 체크아웃의 `demo` 브랜치에서 검토한다. 정식 배포 요청은 없으며 main/gh-pages를 변경하거나 웹사이트를 게시하지 않는다. 데모는 5174·saves-demo·별도 브라우저 저장 키를 사용한다. 기존 정식 저장을 자동 복사하거나 삭제하지 않는다. 작업 환경은 이미 격리되어 있으므로 별도 worktree를 만들지 않는다.

이전 채팅 링크의 대화 본문은 직접 확인하지 못했다. 이 문서는 현재 저장소와 이번 채팅에서 전달받은 요구사항·첨부 자료를 근거로 작성했다.

## 이번 요구사항과 구현

- `Downloads (14).zip`의 마을회관 원본 그림으로 소도시 왼쪽 아래 건물 내부를 구현했다. 카운터 너머 분홍머리 로터스, 앞 왼쪽 하얀 머리 헨델, 앞 오른쪽 모자를 쓴 아델은 배경에 이미 있으므로 중복해서 그리지 않는다.
- 네 인물의 원본 SD·상반신 PNG·MP3를 이름별로 보관했다. 회관은 원본 배경 인물, 대화는 원본 상반신, 실외 마틴은 SD를 사용한다. 목소리는 기존 글자별 재생·공통 음량·무음·취소 규칙을 따른다.
- 하린은 마틴으로 교체했으며 기존 실외 ID `artist`는 유지한다. 첨부 TXT의 대사·선택지를 데이터로 구성했다. 나레이션은 별도 페이지이며 무음이다.
- 마틴의 부탁은 수락 → 마리아에게 전달 → 마틴에게 돌아가 보고 → 완료 순서다. 전달 전 거짓 보고를 해도 선물은 남는다. 마리아에게 누구의 선물이라고 말하든 실제 전달된다. 선물 선택지는 마리아의 기존 꿀빵 부탁 상태와 무관하게 표시된다. 선물은 가방의 소모 재료가 아닌 퀘스트 상태로 보관하며 임의 골드 보상은 추가하지 않았다.
- 로터스에게 좋아하는 빵을 물어본 뒤 베리 빵 선물이 열린다. 가방에 빵이 없으면 버튼이 비활성화된다. 대사를 끝까지 읽어야 1개를 소비한다. 선물은 조합 평가를 올리지 않는다.
- 아델에게 조합 등급, 평가 기준, 다음 평가일, 현재 지원품을 확인할 수 있다. 기존 우체국 소포에 등급별 지원을 적용했다.

## 조합 규칙과 선택한 기본값

게임 1일째를 월요일로 두고 매주 월요일 06:00에 직전 7영업일의 실제 판매 개수를 7로 나눈다. 영업일은 06:00부터 다음 날 06:00까지다. 휴업일은 0개로 포함한다. 평가 후 달성 등급은 유지한다. 판매한 모든 제빵 제품의 수량을 세며, 매출 골드·퀘스트 전달·선물·진열만으로는 판매량이 오르지 않는다.

| 등급 | 일평균 판매 기준 | 매일 지원품 |
| --- | --- | --- |
| D | 시작 등급 | 밀가루 4, 꿀 1 |
| C | 5개 이상 | 밀가루 8, 꿀 2, 이스트 2, 소금 2 |
| B | 10개 이상 | 밀가루 12, 꿀 3, 이스트 4, 소금 4, 버터 2, 설탕 2 |
| A | 20개 이상 | 밀가루 20, 꿀 5, 이스트 6, 소금 6, 버터 4, 설탕 4, 초콜릿 2 |

등급 기준·지원량은 `src/guild.js`의 guildRules에서 조정한다. 시작 요일·기준 수량·등급 유지 정책은 사용자가 숫자를 지정하지 않아 이번 구현에서 선택한 기본값이다. 처음 평가는 8일째다. 소포의 기존 하루 한 번 수령 규칙은 유지하며 당일 승급해도 재수령할 수 없다.

## 저장 호환과 담당 파일

저장 v8의 선택 필드 `civic`과 `guild`를 추가했다. 기존 돈·아이템·진행·호감도를 유지한다. 예전 세이브는 읽은 영업일부터 판매량을 기록하며, 과거 누적 매출에서 판매 개수를 추정하지 않는다. 이관한 주가 불완전하면 그 주는 평가하지 않고 다음 완전한 주를 기다린다.

- `data/civicStories.json`, `data/civicActors.json`, `data/source/*-dialogue.txt`: 원문·대사·선택지·배역.
- `src/civicStory.js`: 회관 대화, 선물 전달/보고와 로터스 선물. 완료 콜백은 재고/단계를 재검사하고 중복 실행을 막는다. ESC 취소 시 정산하지 않는다.
- `src/townStory.js`, `data/townStories.json`: 마리아의 기존 부탁과 새 선물 선택지, 추가 일상 대화.
- `src/guild.js`, `src/dailyReport.js`, `src/wellbeing.js`, `src/shop.js`: 판매 기록·월요일 평가·시계 점프·소포 지원.
- `src/save/civicState.js`: 새 저장 필드의 이관과 검증.
- `data/worldMaps.json`, `src/interior.js`, `src/renderer.js`: 회관 출입·배경·실내 버튼. 회관 앞 기존 건물 충돌 영역도 출입구 높이에 맞췄다.

## 실행과 검증

Node.js 20 이상에서 패키지 설치 없이 `npm start`로 실행한다. 데모 서버는 5174에서 실행된다. 검사에는 개인 세이브를 사용하지 않는다.

```sh
npm test
npm run check
BAKERY_PLAYWRIGHT_MODULE=file:///opt/codex/cua_node/lib/node_modules/playwright/index.mjs BAKERY_BROWSER=/usr/bin/chromium node tools/check-civic-browser.mjs
```

브라우저 도구는 정적 빌드와 임시 호스트·격리 브라우저 저장을 사용한다. 다른 정적 브라우저 도구와 동시에 실행하지 않는다. 제한된 실행 샌드박스에서 로컬 포트나 Chromium 실행이 거부되면 지원되는 실행 권한으로 검사하며 앱 보안을 바꾸지 않는다. Windows 직접 실행과 실제 휴대폰·Safari 검사는 별도다. 최종 검사 결과는 완료 보고를 참고한다.

최종 검증: 전체 테스트 154개 모두 통과, JavaScript 153개 구문 검사 통과. `check-civic-browser.mjs`에서 회관 출입·원본 배경/초상·네 음원 디코딩과 실제 재생·로터스 선물 조건·헨델 대화·실제 판매 후 월요일 A 승급·마틴/마리아 전달 및 보고·저장 재접속·A 지원품의 당일 중복 방지·390px 화면을 통과했다. `check-web-browser.mjs`에서 기존 웹 경로·PC 이동·저장/재접속·JSON 이동·삭제/취소·격리를 통과했다. 이미지/음원 13개는 첨부 원본과 SHA-256이 동일하다. 데모 개발 서버 시작도 확인했다. 정식 배포와 Windows 직접 실행·실물 모바일 검사는 수행하지 않았다.
